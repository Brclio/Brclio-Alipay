## 本地开发

需要 Node.js 22.12+ 或 24+。

```sh
npm ci
npm run check
npm run dev
```

没有配置商户密钥时，首页正常展示；`GET /api/health` 返回 `ready:false`，收款接口拒绝交易。没有假支付成功模式。

## 自动验证与部署

GitHub 的 `main` 推送、Pull Request 和手动运行会执行 `npm run ci:verify`，只验证代码、构建与 Worker 运行时，不读取支付或部署 Secrets。生产自动部署方案使用 Cloudflare Workers Builds；迁移后目标账号的授权与构建配置尚待完成，目前使用受控手动发布。配置步骤与当前状态见[部署文档的自动部署部分](docs/deployment.md#github-自动部署)。GitHub 验证通过不代表生产已经部署。

## 首次设置

```sh
node scripts/bootstrap.mjs
```

应用私钥、应用公钥、收银台令牌密钥存入本机 `secrets/`。已有文件不会被覆盖；该目录已由 Git 忽略。**应用公钥**交给支付宝，**支付宝公钥**交给服务验签，二者不可混用。管理员账户及加密密钥使用 `scripts/configure-admin.mjs` 从标准输入设置，详见管理文档；明文密码不落盘。

## 让 AI 接入产品

打开 `/admin` 登录，填写新平台 ID 或选择已有平台，点击“生成并复制 AI 接入任务”。默认由 AI 读取项目现有套餐，并自动发现/新增该平台所需的公网 HTTPS 来源；初始来源可留空。也可选择人工定价或固定域名范围。复制内容包含完整 Skill 和最长 2 小时的单平台授权，产品开发 AI 可直接读取当前配置、生成版本计划并应用，不需要另附 ZIP。

任务只授予指定平台的新增或修改权限，可在后台撤销；不提供管理员密码、支付宝私钥、GitHub Token 或其他平台凭证。AI 对产品仓库的编辑和发布仍需用户授权。修改平台保留原长期密钥，以版本比较避免覆盖其他任务的更新；平台注册表在私有 GitHub 仓库中加密保存。

只有尚不存在加密注册表时才使用旧 `CLIENTS_JSON` 初始化；已有加密数据损坏或缺少解密 key 时拒绝运行，不退回旧配置。加密 key 必须安全备份并保留。

后台还提供商品改价、停售、权益说明，以及按月/平台的成交统计、日趋势、订单记录和当前页 CSV。营业额为已确认付款金额，未扣手续费与退款；旧账未纳入时提示补建。初次接入会指导产品读取签名商品目录；已有未改造产品需要同步接入，权益规则仍由产品后端执行。

`xhs-downloader` 已完成服务端接入及线上签名目录验证，正式应用与电脑/手机网站支付权限已核实。2026-10-15 首次 ¥3 日付受控实付已验证支付宝付款、GitHub PAID/outbox 送达及产品实际后端会员开通；临时验收关闭后，用户明确授权“正式开放在线收款”，正式配置为 `PAYMENT_ENABLED=true`。该笔验收不代表其他套餐、客户端、手机渠道或退款均已完成实付验证。目录通过 `acceptingPayments` 单独报告实时收款状态，后台配置成功不表示某笔付款或产品权益已经开通。

## 收款与开通

产品后端创建订单 → 统一收银台 → 支付宝 → 验签通知/主动查单 → 原子写入付款及待发送事件 → 产品验签并幂等开通 → 返回产品。

浏览器返回参数只用于定位订单。产品必须通过自己的服务端确认付款、核对商品和金额并幂等开通。`fulfillmentStatus:delivered` 仅表示产品端已返回 HTTP 2xx，产品接收端应当在权益事务提交后才返回 2xx。

支付页会继续查询已付款订单的通知状态，live 通知送达后倒计时返回产品（可留在此页）。产品必须在网页返回或应用 focus/resume 时查询实际权益并刷新账号和功能权限。接入 Skill 与 ZIP 提供完整要求和无密钥等待模板；总收款已开放且产品目录允许收款时，可在已授权的产品项目完成上线，不需重复部署支付中心。

资源节约仅对五个公开 CSS/JS 文件采用直接静态分发，保留安全头与 no-store。付款、查单、通知重试、页面确认流程及每五分钟后台补偿保持原行为；两个入口的静态路由和发布验证见[部署说明](docs/deployment.md)。

目前实现单次付款；自动续订、原生 App SDK、自动退款和退款后的权益撤销不在本版本中。退款需人工处理并在产品侧同步权益。

GitHub 存储适合起步阶段的低交易量；存在 API 配额与提交延迟，不能承诺高并发或数据库级吞吐。商品经营内容、实际收银台和产品域名须满足支付宝签约要求；域名中转不代表免备案。
