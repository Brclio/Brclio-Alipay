## 本次已实现的管理功能

- `/admin` 管理登录、平台列表、手动配置预览与单平台版本保存。
- 创建和更新平台的 AI 接入任务，一键复制完整 Skill 与最长 2 小时的单平台、域名范围授权；只复制任务即可下载通用包，不依赖另附 ZIP。
- 授权列表与撤销能力，不提供管理员密码、支付宝私钥、GitHub Token 或其他平台密钥。
- context → plan → apply 流程，按目标平台版本比较更新，保留原长期凭证、其他平台与历史订单。改价不修改历史订单金额；回调变更需处理待投递通知影响。
- AES-256-GCM 加密 GitHub 平台注册表，保存平台目录、目标凭证、授权哈希、计划和审计。仅加密记录不存在时 legacy 初始化；已有密文损坏或缺 key 时拒绝运行，不退回旧配置。
- 管理 Secret 脚本从 stdin 接收输入，明文密码不落盘，已存加密 key 保留；管理写入使用同源及 CSRF 校验。
- 通用 Skill、仓库扫描器、受限 CLI、服务端模板，以及相应管理、接入及部署文档。

这些功能不等于首个真实产品已完成认证、业务订单关联、验签回调和权益事务，目标产品仍须逐项接入及验收。
